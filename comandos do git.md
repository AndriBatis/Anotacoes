# Comandos do Git

Após criar o repositório no GitHub, faça o comando "git clone" para copiar o repositório para o computador.

> git clone + URL do repositório

Após criar ou alterar arquivos, adicione na árvore de modificações "working tree".

>git add .

Sempre dê um git status para saber o status do repositório.

>git status

Após o passo acima, para separar as alterações efetuadas no trabalho, para serem enviadas para o gitHub.com use:

>git commit -m "e a mensagem exolicando o que foi feito." **E não ESQUECER das aspas duplas ("")**

Por último para enviar as alterações feitas, use o comando:

>git push
